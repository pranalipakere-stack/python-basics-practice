# Python Basics Practice

## About This Repository

This repository contains basic Python programs created while learning Python programming. It focuses on understanding fundamental programming concepts and developing problem-solving skills through practical examples.

## Topics Covered

### 1. Conditional Statements
- if statement
- if-else statement
- if-elif-else statement
- Comparing two numbers
- Checking whether a number is even or odd
- Calculating total marks and percentage with grades

### 2. Loops
- while loop
- for loop
- Nested loops
- Using the range() function
- Printing multiplication tables
- Printing numbers in ascending and descending order

### 3. Loop Control Statements
- break statement
- continue statement
- for-else statement

### 4. Basic Python Programs
- Factorial of a number
- Multiplication table of a user-input number
- Prime number checking
- Printing characters using a for loop
- Generating multiples using range()

### 5. Pattern Printing
- Star patterns
- Hash and ampersand patterns
- Triangle patterns using loops

## Tools Used
- Python
- Jupyter Notebook

## Learning Objective

The objective of this practice repository is to strengthen Python fundamentals, understand program flow, and improve logical thinking through hands-on coding exercises.
